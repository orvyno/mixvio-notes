# MixVio Field Notes

Hands-on test notes from the [MixVio AI](https://mixvio.ai/?utm_source=github&utm_medium=readme&utm_campaign=field_notes&utm_content=index_link) team: real runs, logged costs, failures included, and the prompts we would reuse.

## How these notes are made

- Every number comes from a run we made and logged. Nothing is estimated from vendor claims.
- Failed and unusable outputs stay in the data.
- Prices, wait times and model behavior are dated snapshots; they change.
- All tests run on MixVio, which we build. We say so in each note, and we do not present single-platform tests as platform comparisons.
- AI-generated images and clips are labeled as such. Text may be edited with an AI writing assistant; data is not.
