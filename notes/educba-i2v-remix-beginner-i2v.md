## Source checklist

- [ ] Clear subject
- [ ] Depth (FG / mid / BG)
- [ ] Resolution OK for short push-in
- [ ] Sparse logos / micro-text; avoid heavy compression
- [ ] Rights OK · JPEG/PNG/WebP · Chrome
- [ ] Private workspace assets; providers process the run

Illustrative contrast card (local path only): `assets/AS2_source-good-vs-weak_1600x900.png`

## Upload + prompt

Open the [image-to-video effect workspace](https://mixvio.ai/tools/image-to-video?utm_source=github&utm_medium=notes&utm_campaign=educba-i2v-remix&utm_content=educba-i2v-remix-github-workspace-inline#effect-workspace). One owned first frame (+ optional last frame if supported). Do **not** mix a multi-reference pack into the same I2V job.

Prompt = camera + subject + environment + mood. Avoid “make it move.”
